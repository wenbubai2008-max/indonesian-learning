词根 / 前后缀

理解词族

mengatasi ← atas

meng- + atas + -i → mengatasi：解决、克服、应对。常见：atasi masalah / mengatasi masalah。

menentukan ← tentu

meN- + tentu + -kan → menentukan：决定、确定。词族：tentu / tertentu / ketentuan。

menyelesaikan ← selesai

meN- + selesai + -kan → menyelesaikan：完成、解决。词族：selesai / penyelesaian。

menyadari ← sadar

meN- + sadar + -i → menyadari：意识到。词族：sadar / kesadaran。
